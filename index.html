Half-Life 2 Lambda Cache Tracker

Stuck trying to complete the Lambda Locator achievement in Half-Life 2? This tool helps you track down the caches you've missed by reading your gamestate.txt file and showing you which of the 45 lambda caches you've found and which ones are still missing.

Check your caches

Upload the gamestate.txt file from your Half-Life 2 install directory. Everything is processed in your browser — the file is never sent to a server.

Frequently asked questions

How many lambda caches are there in Half-Life 2?

There are 45 lambda caches in Half-Life 2, spread across 11 chapters from A Red Letter Day to Follow Freeman. Finding all of them completes the Lambda Locator achievement.

How do I find my gamestate.txt file?

In Steam, right-click Half-Life 2, choose Properties, open the Installed Files tab and click Browse. Then open either the hl2 or hl2_complete folder — gamestate.txt sits at the top level.

Should I use the hl2 or hl2_complete folder?

Use hl2_complete if you have Episode One and Episode Two installed, or the 20th Anniversary Edition of Half-Life 2. Otherwise use hl2.

Is my gamestate.txt uploaded to a server?

No. The file is read locally in your browser and never leaves your computer; the site has no server-side component.

What does the tracker read from gamestate.txt?

It extracts the data value from the GameState block entry with id 86. That value is a 45-bit mask: bit N-1 is set when cache N has been found, which is how the tool lists found and missing caches per chapter.

Do I need to install anything?

No. The tracker is a single static page with no dependencies, no build step and no account — open it in any modern browser.
